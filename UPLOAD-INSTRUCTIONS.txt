نسخة GitHub من آخر تصميم معتمد - 9 سبتمبر 2026

1. فك ضغط ملف ZIP.
2. افتح مستودع tarekalsoudani.github.io على GitHub.
3. اختر Add file ثم Upload files.
4. ارفع جميع الملفات ومجلد cv إلى المجلد الرئيسي للمستودع، واستبدل الملفات المتكررة.
5. اضغط Commit changes.
6. بعد اكتمال النشر، حدّث الصفحة باستخدام Ctrl + F5.

ارفع المحتويات مباشرة، وليس ملف ZIP أو مجلدًا إضافيًا يحتويها.
لا تحتاج npm أو أدوات بناء. ملف السيرة الذاتية المرفق هو CV v9.
